# ADR-0004 — v1 只加语言风格、体量预算、使用统计三件事

## 背景

除可见性、排序、描述改写之外，还有七个候选能力：语言/写作风格、体量预算、使用统计、tools 预批准、默认参数预设、model/thinking 覆盖、健康检查。全做会把插件变成第二个 `settings.json`。

## 决定

v1 只做：

- **语言与写作风格**：每个 skill 可约定回答语言与风格，折进改写后的描述。
- **体量预算**：已由 ADR-0005 退役 —— 选中只注入路径，不再有整篇 body 需要设上限。
- **使用统计**：记录选中次数与最近选中时间，能列出长期未用到的 skill。

## 被否决的选项

- **tools 预批准、默认参数、model/thinking 覆盖**：这三项都是运行时调参，pi 已有 settings 与 skill frontmatter 承载，重复提供会产生"改了不生效"的困惑。
- **健康检查**（重复 description、触发词撞车、body 过大）：属于一次性审计，做成独立 lint skill 比塞进插件主路径更轻，也不占用运行时。
- **一次做全七个**：每个都要定义默认值、合并规则与诊断信息，v1 会被配置语义淹没。

## 后果

- 使用统计需要本地持久化一份按 skill 的计数，与偏好文件分开存，避免偏好文件被高频写入。
- 体量预算只影响选中注入时送出的内容，不改磁盘上的 `SKILL.md`。
- 语言与风格是软约定：写进描述，不承诺模型必然遵守。
